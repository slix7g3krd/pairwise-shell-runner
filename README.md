# pairwise-shell-runner

运维平台一开放自定义命令，命令注入就防不住：subprocess 直接 shell=True，参数用空格拼成字符串；用户输入里的 ; | & $() 反引号全不转义；环境变量从请求体合并进子进程，PATH 和 LD_PRELOAD 可被覆盖；命令白名单只匹配前缀，`ls; rm -rf` 也能过；超时设成 0 表示不限；输出不截断，GB 级日志打爆内存；工作目录由用户指定，能切到任意路径；参数里的换行能追加第二条命令；命令替换和进程替换没有禁用；后台进程不清理；退出码被忽略；stderr 直接回显；sudo 包装器没有降权；临时脚本权限 777；清理逻辑只在成功时执行。security/shell_runner.py 是核心，tests/test_shell_runner.py 15个红。要修的是：禁用 shell；参数数组化；元字符与换行；环境变量白名单；精确命令白名单；强制超时；输出截断；固定工作目录；禁用替换；进程组清理；退出码检查；stderr 脱敏；最小权限；临时文件权限；finally 清理。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
